## 09. Logo 与矢量母版

### 9.1 标志家族

按实际需要制作 primary horizontal、wordmark、symbol、compact/stacked、micro。没有价值的 monogram 或垂直版不必硬造，记录原因即可。

支持全彩、纯黑、纯白、单色以及指定背景用法。说明中文名、英文名、标语、域名如何组合；未确认的副标不进入正式交付。

### 9.2 真实几何与编辑性

- 图形 Logo、符号、几何图案的权威几何来源应为干净、可编辑的 SVG 或明确的矢量生成源。
- 不允许把 PNG/JPEG/base64 栅格图片包在 SVG 中冒充矢量。
- 母版保留合理的路径、分组、变换与命名；不要为压缩体积破坏可编辑性。
- 发布版可做路径优化；不要把经过不可逆扁平化的发布版反过来当母版。
- 字标保留可编辑文字布局/来源信息，并生成文字已正确转路径的便携发布版。
- 未成功完成字体转路径时，标明“依赖字体的草稿”，不要用错误字形或手描近似冒充完成。

### 9.3 色彩来源不重复维护

Logo 的几何与颜色决策分开。可使用受控的 SVG 模板/颜色角色生成各个配色发布版。

Standalone 发布 SVG 必须自行渲染正确，不能依赖宿主网页才存在的 CSS 变量或外部字体。组件内联版本可以使用 `currentColor`，但应与固定色的下载版分开命名。

### 9.4 图形质量

规范 viewBox、边界、留白、比例、负空间、视觉中心、字距、光学校正、反白补偿、单色复现、最小尺寸与背景规则。构造网格用于说明实际结构，不事后编造“黄金比例”故事。

符号和微型标志要实际渲染在 16、20、24、32、48、64 px 预览；另检查较大导出。全字标按其用途设最小宽度，不要求整个长字标塞进 16×16。

不要只放大截图判断微型效果。检查 1×/2×、浅/深背景、圆形/圆角矩形裁切与灰阶。过细描边、闭塞负空间、光学偏心必须修正。

SVG 发布检查包括有效 XML、viewBox、非法外部引用、脚本、事件属性、意外 `foreignObject`、裁切错误、ID 冲突和渲染差异。装饰 SVG 与有意义 SVG 提供不同的可访问嵌入示例。结构类检查用 `<skill>/scripts/svg_lint.py <文件或目录>`；渲染差异仍需实际渲染比对。
