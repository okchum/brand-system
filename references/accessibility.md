## 13. 可访问性、响应式与动效

以 WCAG 2.2 AA 的适用条款为最低目标；在不破坏体验时争取更高的阅读与操作质量。目标不等于已经取得合规结论。

文本配对按适用条件测试：普通文字至少 4.5:1，大号文字至少 3:1；所需非文本信息按相关条款测试 3:1。大号文字的判定、禁用内容和 Logo 等例外必须按官方规范处理，不把豁免内容机械判失败，也不拿 Logo 豁免放宽正文要求。

关键正文可争取 7:1，但不能因此宣称整个产品 AAA。对比度计算需考虑实际合成背景、透明度、渐变和状态，而不是只测调色板孤立值。

检查键盘路径、焦点可见且不被遮挡、可访问名称、错误关联、色彩独立信息、屏幕阅读器基本语义、文字缩放、重排、文本间距、主题对比和必要时 forced-colors。

触控优先争取 44×44 CSS px 或适用原生平台推荐值；区别“内部设计目标”和 WCAG 2.2 AA 2.5.8 的 24×24 CSS px/例外规则。不得宣称所有小于 44 px 的控件都不符合 AA。

检查至少窄手机、宽手机、平板、桌面与密集屏幕；测试宽度写入配置，不把设备型号表当永久标准。RTL 仅在语言范围需要时实施，否则记录未来扩展方法。

动效定义目的、duration、easing、距离、进入/退出、加载、成功/错误反馈及取消行为。遵循 `prefers-reduced-motion`，提供无位移或弱动效替代，避免不必要的闪烁和持续运动。

自动化扫描不能代替全部可访问性检查。报告区分自动验证、视觉审阅、键盘检查、辅助技术检查和未执行项。
